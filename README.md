# adtof-gui

Web app (FastAPI) and desktop GUI to transcribe drums from a local audio file using [ADTOF-pytorch](https://github.com/xavriley/ADTOF-pytorch).

```bash
python main.py      # Onirógrafo web UI at http://127.0.0.1:8888
python main_gui.py  # desktop window
```
